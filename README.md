# jev-sheets

Google Sheets custom functions for [Jev](https://docs.typesafe.ai/) using Google Apps Script.

スプレッドシート上から、通常の関数と同じ感覚でJevによる判定・分類・スコアリングを実行する。

```
=JEV_NOUL(A2, "この商品は安全靴ですか？")              → 0.96   条件に該当する確率 (0〜1)
=JEV_CHOICE(A2, "カテゴリを判定してください", C2:C6)    → 安全靴  選択された候補
=JEV_SCORE(A2, "不満度を評価してください", C2:C5)       → 1.08   確率分布から算出した連続値
```

## 使い方

### JEV_NOUL(state, instruction)

二値的な判断をさせ、**条件に該当する確率**を数値で返す。

| 行 | A（商品名） | B（安全靴らしさ） |
| --- | --- | --- |
| 2 | 先芯入り作業靴 JSAA A種 樹脂先芯 26.0cm | `0.96` |
| 3 | 綿100% 長袖Tシャツ Mサイズ | `0.01` |

```
B2: =JEV_NOUL(A2, "この商品は安全靴ですか？")
```

確率なので、しきい値で分岐させると使いやすい。

```
=IF(JEV_NOUL(A2, "この商品は安全靴ですか？") >= 0.8, "安全靴", "要確認")
```

### JEV_CHOICE(state, instruction, choices)

候補の中から最も適切なものを選び、**候補名の文字列**を返す。

| 行 | A（商品名） | B（判定カテゴリ） | C（候補） |
| --- | --- | --- | --- |
| 2 | 先芯入り作業靴 JSAA A種 26.0cm | `安全靴` | 作業服 |
| 3 | ベルトループ付き作業ズボン | `作業服` | 安全靴 |
| 4 | | | 手袋 |
| 5 | | | 靴下 |
| 6 | | | その他 |

```
B2: =JEV_CHOICE(A2, "この商品を最も適切なカテゴリに分類してください", $C$2:$C$6)
```

候補は `"作業服|安全靴|手袋|靴下|その他"` のように文字列でも書ける。
空セルは除外され、重複は1つにまとめられる。候補は2つ以上必要。

### JEV_SCORE(state, instruction, levels)

評価段階に対するスコアリングを行い、**0 〜 (段階数 - 1) の連続値**を返す。

| 行 | A（レビュー） | B（不満度） | C（評価段階） |
| --- | --- | --- | --- |
| 2 | 対応は丁寧でしたが、納期が一日遅れました。 | `1.08` | 不満なし |
| 3 | 同じ不具合で三度も問い合わせています。いい加減にしてほしい。 | `2.99` | 少し不満 |
| 4 | | | 不満 |
| 5 | | | 非常に不満 |

```
B2: =JEV_SCORE(A2, "顧客の不満度を評価してください", $C$2:$C$5)
```

Jevは段階を1つ選ぶのではなく **各段階に当てはまる確率** を返す。スコアはそれを段階の番号
（上から 0, 1, 2, 3）で重み付けして合計した期待値なので、整数にならない。

| 入力 | 不満なし<br>(0) | 少し不満<br>(1) | 不満<br>(2) | 非常に不満<br>(3) | スコア |
| --- | --- | --- | --- | --- | --- |
| 納期が一日遅れました | 0 | 0.92 | 0.08 | 0 | **1.08** |
| 三度も問い合わせています | 0 | 0 | 0.01 | 0.99 | **2.99** |

```
1×0.92 + 2×0.08 = 1.08
2×0.01 + 3×0.99 = 2.99
```

`1.08` は「ほぼ『少し不満』だが、わずかに『不満』寄り」。段階を1つだけ選ぶ方式では
捨てられる中間の度合いが数値として残るので、平均・並べ替え・しきい値にそのまま使える。

```
=AVERAGE(B2:B100)
=IF(B2 >= 2.5, "要対応", "")
=INDEX($C$2:$C$5, ROUND(B2) + 1)   段階名に戻す → 1.08 なら「少し不満」
```

評価段階は **低い方から順に** 並べること。順序が変わると番号の割り当ても変わる。

### 共通

- `state` にはセル範囲も渡せる（複数列を渡すと項目名と値の対応ごと送られる）
- 候補・評価段階は `$C$2:$C$6` と絶対参照にすると、下方向へコピーしてもずれない
- 同じ入力の再計算はキャッシュから返るためAPIを消費しない
- エラーは `JEV: ...` の形でセルに表示される（一覧は [docs/setup.md](docs/setup.md)）

## クイックスタート

```bash
npm install
npx clasp login
```

`.env` に2つ設定する（Git管理外）。

```bash
JEV_API_KEY=...      # TypeSafe APIキー
JEV_SCRIPT_ID=...    # デプロイ先スプレッドシートのスクリプトID
```

```bash
npm test          # 単体テスト（ネットワーク不要）
npm run try       # 実際のJev APIを叩いて確認
npm run push      # build後に clasp push
```

push後、Apps Script側のスクリプトプロパティにも `JEV_API_KEY` を登録する。
手順の詳細は [docs/setup.md](docs/setup.md)、開発の詳細は [docs/development.md](docs/development.md) を参照。
